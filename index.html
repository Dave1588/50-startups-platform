診斷指標

方差膨脹因子 (Variance Inflation Factor, VIF)

量化特徵間的嚴重共線性問題。若特徵之 VIF > 5 或 10，代表該特徵高度可由其他特徵線性預測，會導致回歸係數標準誤放大。

R&D Spend VIF = 2.50 良好 (無共線性)
Marketing Spend VIF = 2.42 良好 (無共線性)
State_Florida VIF = 1.39 良好
State_New York VIF = 1.34 良好
Administration VIF = 1.18 良好

各特徵 VIF 數值分佈

全部自變數 VIF 皆小於 2.5，代表本資料集無嚴重多重共線性，可安心進行線性回歸。

假設檢定策略

反向淘汰法 (Backward Elimination with OLS)

從全模型開始，每次剔除 p-value 最高且大於顯著水準（α = 0.05）之特徵，直到所有保留特徵皆顯著。

Step 3
剔除 Administration Max p-value = 0.6018 (> 0.05，行政費用與獲利無關)
Step 4
剔除 Marketing Spend Max p-value = 0.0600 (略高於 0.05 臨界值)
Final
保留特徵：[R&D Spend] p-value < 0.0001，極度顯著驅動獲利

L1 嵌入式正則化

LassoCV (Least Absolute Shrinkage and Selection Operator)

利用 L1 範數懲罰項將無影響力的回歸係數精確壓縮至 0，達成自動稀疏特徵選擇，有效防範過擬合。

SYNTHESIS & RECOMMENDATIONS

5 大特徵選取演算法決策矩陣

橫向評估各演算法的機制、計算成本、共線性處理能力與最終選拔結論：

演算法 類型 篩選入選特徵 特徵數 主要優勢 侷限性 推薦應用情境
1. VIF 統計檢驗 全部（無共線性） 5 精確揪出膨脹係數，避免共線性陷阱 無法評估與 y 的直接相關度 建模前的首要共線性診斷
2. Backward OLS 封裝法 (p-val) [R&D Spend] 1 統計學嚴謹，具有可解釋 p-value 對多重共線性較敏感，易剔除潛在變數 重視統計顯著性之學術或醫學回歸
3. RFECV 封裝法 (CV) [R&D, Marketing] 2 結合 K 折交叉驗證，抗過擬合力強 計算量較大，每次需反覆擬合 機器學習管線自動化維度搜尋
4. LassoCV 嵌入式 (L1) [R&D, Marketing, Admin] 3 係數精準收縮至 0，同時完成正則與選取 高度相關變數中只會隨機挑選其一 高維度特徵（p > n）稀疏建模
5. Forward Stepwise 貪婪搜尋 [R&D, Marketing] 2 直觀展現特徵增加曲線，明確指出甜蜜點 若特徵量極大時運算成本較高 新創獲利預測之首選最佳實踐 ⭐
DEPLOYMENT GUIDE

GitHub Pages 一鍵部屬指南

本分析平台為純靜態現代 Web 專案（HTML5 + Vanilla CSS + ES6 + Chart.js），可直接部屬於 GitHub Pages：

步驟 1

建立 GitHub 儲存庫

前往 GitHub New Repository 建立一個新的公開儲存庫（例如 50-startups-feature-selection）。

步驟 2

在本地終端推動代碼

在當前目錄執行以下 Git 指令：

git init git add . git commit -m "feat: 50 Startups 5大特徵選取演算法分析平台與即時推論模擬器" git branch -M main git remote add origin https://github.com/<您的GitHub帳號>/<專案名稱>.git git push -u origin main
步驟 3

開啟 GitHub Pages 服務

進入儲存庫 Settings ➡️ 點擊左側 Pages ➡️ 在 Branch 選取 main / / (root) 並點擊 Save。

幾秒後即可獲取專屬網址：https://<您的GitHub帳號>.github.io/<專案名稱>/
